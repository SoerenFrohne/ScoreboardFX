# 1. IDE starten
Bisher fehlte mir die Zeit eine ausführbare exe-Datei zu erstellen. 
Aus diesem Grund muss die Software von der Entwicklungsumgebung aus gestartet werden. Hierzu muss man "IntelliJ" öffnen. 
Ich hatte es auf einen der Laptops installiert.

# 2. Windows vorbereiten
Über Windows-Taste + P muss "Erweitern" ausgewählt werden.

# 3. Projekt auf den neuesten Stand bringen
In IntelliJ den Menüpunkt "Git" und dann "Pull" auswählen. Nochmal mit "Pull" bestätigen. 
Das Projekt ist jetzt auf dem neuesten Stand.

# 4. Die Software starten
In der rechten Ecke ist ein Play-Symbol "▶". Hierüber kann die Software gestarten werden.
Neben dem Symbol sollte "ScoreboardFC [run]" ausgewählt sein.

# 5. Einstellungen
In den Einstellungen können Logos und Teamnamen festgelegt werden. Am besten nimmt man hier kurze Teamnamen
(beispielsweise "HVE" statt "HVE Villigst Ergste"), damit diese nicht zu lang dargestellt werden.
